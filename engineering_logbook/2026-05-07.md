## Platform Decision — Pi5 OS Change

**Decision (2026-05-07)**: Switch Pi5 from Ubuntu 24.04 LTS to Raspberry Pi OS (Debian 13 Trixie).

**Reason**: Ubuntu 24.04 ships libcamera 0.2.0 which cannot support Raspberry Pi cameras
with the current Raspberry Pi package set. The Raspberry Pi libcamera 0.5.x packages have
hard dependency conflicts with Ubuntu 24.04 (require Python < 3.12, `libjpeg62-turbo`,
`libavcodec59` — all Debian Bookworm/Trixie-specific). Raspberry Pi OS has full camera
support out of the box via `rpicam-apps` and libcamera 0.7.0.

**Additional finding**: Camera module is **IMX708** (Raspberry Pi Camera Module 3), not
IMX500. IMX500 firmware installation was unnecessary. IMX708 is detected and fully functional
on Raspberry Pi OS without any extra packages.

**Pi5 OS after flash**: Raspberry Pi OS (Debian GNU/Linux 13 Trixie), kernel 6.12.75+rpt-rpi-2712,
libcamera 0.7.0+rpt20260205, libpisp 1.4.0.

**Impact**: M1.0 platform access re-verified — see section below. Pi400 remains on Ubuntu
and is unaffected.
