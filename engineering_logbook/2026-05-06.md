## Limitations / Notes

- SSH authentication is not available from the automated session. Ping and UDP test execution
  must be performed manually by the operator.
- The scripts use standard library only (no third-party packages required).
- UDP port 5005 must not be blocked by a firewall on Pi 400. If the receiver shows no messages,
  check: `sudo ufw status` and allow port 5005 if needed:
  `sudo ufw allow 5005/udp`
- If the repository has not been synced to Pi 400, transfer the receiver script manually:
  `scp pi400_supervisor/scripts/udp_receiver.py yunpeng@192.168.0.51:~/`
  Then run: `python3 ~/udp_receiver.py`
