## Platform Decision — Pi5 OS Change

**Decision (2026-05-07)**: Switch Pi5 from Ubuntu 24.04 LTS to Raspberry Pi OS (Bookworm 64-bit).

**Reason**: Ubuntu 24.04 ships libcamera 0.2.0 which does not support the Raspberry Pi AI
Camera (IMX500). The Raspberry Pi libcamera 0.5.x packages (which do support IMX500) have
hard dependency conflicts with Ubuntu 24.04 (require Python < 3.12, `libjpeg62-turbo`,
`libavcodec59` — all Debian Bookworm-specific). Raspberry Pi OS (Bookworm) has full IMX500
support out of the box via `rpicam-apps`.

**Impact**: M1.0 platform access steps (SSH, static IP, repo clone) must be re-verified
after the OS flash. Pi400 remains on Ubuntu and is unaffected.
