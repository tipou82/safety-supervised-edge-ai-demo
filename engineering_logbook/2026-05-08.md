## ROS2 Installation — Build from Source on Bookworm

### Decision rationale

| Option | Outcome |
|---|---|
| ROS2 Jazzy via apt on Bookworm | No packages available for Bookworm |
| Docker + ROS2 Jazzy on Trixie | Reintroduces libcamera mismatch inside container |
| Ubuntu 22.04 | Same libcamera incompatibility as 24.04 (upstream libcamera, no RPi IPA) |
| **Build ROS2 Humble from source on Bookworm** | **Camera works natively; Python 3.11 supported by Humble** |

### Environment

| Item | Value |
|---|---|
| OS | Raspberry Pi OS Bookworm (Debian 12) |
| Kernel | 6.12.75+rpt-rpi-2712 |
| Python | 3.11.2 |
| ROS2 | Humble (built from source) |
| Build time | ~49 min total (287 packages across two colcon runs) |
| Install path | `~/ros2_humble/install/` |

### Build steps executed

| Stage | Command | Result |
|---|---|---|
