## M1.0b – Direct Ethernet Software Smoke Test

> **Scope reminder**: This smoke test verifies basic UDP communication only.
> It is **not** a watchdog implementation and does **not** make runtime safety decisions.
> No ISO 26262 compliance or ASIL-B certification is claimed.

### Network Parameters Used

| Parameter | Value |
|---|---|
| Pi 5 direct Ethernet IP | 192.168.50.10 |
| Pi 400 direct Ethernet IP | 192.168.50.20 |
| UDP port | 5005 |
| Message interval | 1 second |
